# Our pictures

Drop image files in this folder and they appear in the album automatically —
no code changes needed.

- Formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif` (upper-case extensions work too).
- Order: alphabetical by file name, so `01-first-date.jpg`, `02-beach.jpg`, … keeps a story.
- Caption: taken from the file name — `2024-06-first-trip.jpg` becomes “first trip”.
  Name the file after the memory and the caption writes itself.
- Portrait (taller) pictures look best in the album frames.
